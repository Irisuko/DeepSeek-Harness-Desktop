添加一次平台和 API Key，Chat 与 Harness 均可使用。各平台独立保存密钥，模型列表根据已添加的平台生成。

DeepSeek 模型优先使用官方平台，其次 OpenCode Go，最后 OpenCode Zen；GPT 和 Claude 使用 OpenCode Zen。
